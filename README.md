# DataPulse
## Problem statement
Modern data pipelines span multiple layers, tables, dependencies, and processing jobs, making it difficult to quickly answer a simple question: “Where is my data, and what happened to it?” Investigating missing or stuck data often means manually tracing records across pipelines, checking job runs and logs, and piecing together project-specific knowledge.

DataPulse is an AI-powered data analyst copilot that understands the structure and flow of a data project and intelligently traces data across its pipeline. It identifies where data is missing, delayed, or stuck, then investigates the underlying cause using pipeline, dependency, and execution evidence.

When a problem is found, DataPulse goes beyond diagnosis - it recommends the appropriate corrective action and can execute and verify the fix with human approval.

From tracking data to understanding failures to resolving them, DataPulse turns complex data troubleshooting into a guided, intelligent workflow.
